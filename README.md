# 广告片展示网站

纯静态广告片展示网站。**没有构建步骤、不用装依赖**，双击 `index.html` 就能在浏览器里打开；也可以直接部署到 GitHub Pages / Netlify / 任意静态托管。

## 目录结构

```
vigour-film/
├─ index.html            页面（双击即可打开）
├─ styles.css            全部样式
├─ app.js                交互逻辑（无依赖，传统脚本）
├─ assets/               站点静态资源（hero 背景图等）
├─ 待导入/                网页「添加作品」按钮与手动导入共用的暂存文件夹
├─ data/
│  ├─ works.json         ← 作品数据（可手动编辑标题/分类/简介）
│  └─ works-data.js      由 works.json 生成，页面实际读取的文件
├─ media/
│  ├─ video/   转码后的播放视频  (H.264 + AAC 的 .mp4)
│  ├─ preview/ 悬停预览片段     (960 宽，无声音)
│  ├─ poster/  海报原图         (宽边最多 1600px)
│  ├─ thumb/   网格缩略图       (宽边最多 720px)
│  └─ image/   图片作品
├─ tools/                导入脚本（Node.js，需要已安装 Node）
├─ 待导入/                把要发布的新文件丢进来
├─ 导入新作品.bat         一键导入：转码 → 海报 → 缩略图 → 更新数据
└─ 重建数据.bat           手动改过 works.json 后重新生成 works-data.js
```

## 导入新作品

有两种方式，任选其一：

- **网页上传**：点页面顶部/作品区的「添加作品」按钮，选好文件后浏览器会把它保存到 `待导入` 文件夹（需 Chrome / Edge；Safari / Firefox 会提示手动放入）。
- **手动**：把视频 / 图片拖进 **`待导入`** 文件夹（支持 .mp4 .mov .m4v .webm .mkv .avi .mts .m2ts .wmv .flv .ts 及常见图片格式）。

选好文件之后：
2. 双击 **`导入新作品.bat`**，等待转码完成（窗口会显示每个文件的进度）；网页上传时如果已处于 `待导入` 文件夹，直接双击即可。
3. 刷新浏览器即可看到新作品。

导入器会：
- 让脚本无法播放的源码（如 HEVC 的 .mov）自动转码为 **H.264 + AAC 的 MP4**，保证 Chrome / Edge / 手机都能播；
- 超大分辨率（4K / 8K）自动缩小到 **1920 宽**，竖屏视频保持原样；
- 自动生成**海报、缩略图、悬停预览片段**；
- 同一文件只会导入一次（按 文件名+大小 判断），重复运行不会重复添加；
- 文件名带数字会自动加空格，例如 `广告片2` → `广告片 2`；分类有默认猜测（可改）；
- 作品在页面与数据文件中**按名称排序**（自然数序：`广告片 2` 排在 `广告片 10` 之前），与导入先后无关。

### 改标题 / 分类 / 简介

用记事本打开 `data/works.json`，找到对应作品修改后，双击 **`重建数据.bat`** 即可。

```json
{
  "title": "作品标题",
  "titleEn": "",
  "category": "广告片",
  "year": 2026,
  "client": "",
  "description": "一句话介绍这部片子"
}
```

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（例如 `vigour-film`），把整个 `vigour-film` 文件夹推送上去（不要忽略 `media/`）。
2. 仓库 Settings → Pages → Source 选 `main` 分支的根目录。
3. 完成，访问 `https://<你的用户名>.github.io/vigour-film/`。

> 注意：GitHub Pages 单文件上限 100MB、仓库建议 1GB 以内。当前转码后整体约 110MB，还有充足余量。

## 技术说明

- 无 ES modules、无 fetch、无外部 CDN——全部是相对路径的静态文件，所以**双击本地也能运行**。
- 视频只转码一次，页面在需要时才加载（海报懒加载、预览片段按需加载）。
- 键盘支持：
  - 放映层内：`← →` 切换作品、`空格` 播放/暂停、`F` 全屏、`M` 静音、`Esc` 退出；打开后焦点落在标题上，快捷键无需先点按钮。
  - 焦点在进度条上时：`← / →` 后退/前进 5 秒，`PageUp / PageDown` 10 秒，`Home / End` 跳到开头/结尾。
  - 浏览器不支持全屏 API 时（部分 iPhone），全屏按钮会自动隐藏。
- 全屏播放**铺满整个屏幕**：视频/图片等比缩放居中（`object-fit: contain`，不拉伸变形），控制条改为浮在画面底部的半透明覆盖层（带安全区适配），不再挤占视频区域。
- 移动端、`prefers-reduced-motion`（减弱动效）、键盘焦点管理与读屏播报均已适配。

## 需要什么

- **导入功能需要 Node.js**（也可以只双击 `index.html` 看图，不看导入）。
  没装的话去 https://nodejs.org/zh-cn 下载 LTS 版。
- 转码依赖 `ffmpeg`，导入脚本会自动调用系统里已有的 ffmpeg（若提示找不到，请安装并把可执行文件加入 PATH）。
